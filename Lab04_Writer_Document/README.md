# Lab 4: Create and format a professional document using LibreOffice Writer

## Aim
To create and format a professional document using LibreOffice Writer with text formatting, tables, headers, footers and page numbering.

## Sample file
`BCPS_Lab4_Writer_Document.docx` (opens directly in LibreOffice Writer; use File > Save As > ODF Text Document (.odt) if you want the native format).

## Procedure
1. Open **LibreOffice Writer** (File > New > Text Document).
2. **Title:** type the title, select it, and set Font = Liberation Serif/Arial, Size = 20 pt, Bold, Centered (`Ctrl+E`).
3. **Headings:** type each section heading and apply Paragraph Style = *Heading 1* from the styles box (or `Ctrl+1`).
4. **Text formatting:** select text and use Bold (`Ctrl+B`), Italic (`Ctrl+I`), Underline (`Ctrl+U`), Font colour, Font size, and Justify (`Ctrl+J`).
5. **Bulleted list:** Format > Bullets and Numbering, or press `F12` for numbering and `Shift+F12` for bullets.
6. **Table:** Insert > Table (`Ctrl+F12`), set Columns = 4, Rows = 5, then enter data. Select the header row, then Table Properties > Background to colour it, and make the text bold.
7. **Header:** Insert > Header and Footer > Header > Default Style, then type the header text.
8. **Footer:** Insert > Header and Footer > Footer > Default Style.
9. **Page number:** put the cursor in the footer, then Insert > Field > Page Number. To show "Page X of Y", type `Page `, insert Page Number, type ` of `, then Insert > Field > Page Count.
10. **Margins and page setup:** Format > Page Style > Page, set margins to 2.5 cm.
11. Save with `Ctrl+S`, and export as PDF using File > Export as PDF.

## Result
A professionally formatted document with a title, headings, formatted text, a table, header, footer and automatic page numbers was created.
