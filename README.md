| Lab No. | Topic | Folder |
|---|---|---|
| 1-2 | CLI commands (mkdir, cd, dir/ls, rmdir) and basic file management | `Lab01-02_CLI_File_Management` |
| 3 | System configuration and networking commands using CLI | `Lab03_System_Networking_CLI` |

| 5 | Personalized invitation letters using Mail Merge | `Lab05_Mail_Merge` |
| 6 | Student marksheet in LibreOffice Calc (SUM, AVERAGE, MAX, MIN) | `Lab06_Calc_Marksheet` |
| 7-8 | Attendance, salary calculation and inventory management in Calc | `Lab07-08_Calc_Attendance_Salary_Inventory` |
| 9-10 | Educational presentation in LibreOffice Impress | `Lab09-10_Impress_Presentation` |

Every folder has a `README.md` with the aim, steps, commands/formulas and the expected result.
Output screenshots go in a `screenshots/` folder inside each lab folder (take them on your own system while running the steps).

## How to upload this on GitHub
```bash
cd bcps-lab-experiments
git init
git add .
git commit -m "BCPS practical: labs 1-10"
git branch -M main
git remote add origin https://github.com/<your-username>/bcps-practical.git
git push -u origin main
```
(Create an empty repository named `bcps-practical` on github.com first.)
