# Lab 9-10: Develop an educational presentation in LibreOffice Impress using themes, slide transitions, animations and multimedia objects

## Aim
To develop an educational presentation on "Introduction to Artificial Intelligence" using themes, transitions, animations and multimedia objects.

## File
`Introduction_to_AI.pptx` is a 7-slide starter deck. Open it in Impress, then add the transitions, animations and multimedia from the steps below (these are the practical's required parts, and you should do them yourself for the screenshots).

## Slides
1. Title slide
2. What is Artificial Intelligence?
3. Types of AI
4. Machine Learning Workflow (shapes)
5. Applications of AI
6. Advantages and Challenges
7. Conclusion and thank you

## Procedure
**1. Theme / master slide**
- View > Master Slide to edit the master. Slide > Slide Properties > Background to set the colour. Or use the Slide Design panel (View > Sidebar > Slide Properties/Master Slides) to apply a built-in theme.

**2. Slide transitions**
- Select a slide, open the Slide Transition panel in the sidebar (or Slide > Slide Transition), choose an effect (Fade, Push, Wipe), set speed = Medium, and click **Apply to All Slides** if needed.

**3. Animations**
- Select the text or object, then Animation panel (sidebar) > **+ Add**. Choose Entrance > Fly In / Appear / Zoom, set Start = On click, speed = Medium, and use the Play button to preview.

**4. Multimedia objects**
- Image: Insert > Image.
- Audio/Video: Insert > Audio or Video (mp3, mp4).
- Shapes and diagrams: Insert > Shape.
- Chart: Insert > Chart (use for the "AI adoption" data if you want).

**5. Run and save**
- Press `F5` to run the slide show, then save as `.odp` and export as PDF if needed.

## Result
An educational presentation was prepared with a theme, transitions, animations and multimedia objects.
